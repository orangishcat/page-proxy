# Install Page Proxy

Download the latest release from GitHub:

- [Latest release](https://github.com/orangishcat/page-proxy/releases/latest)

## Chrome (.crx)

1. Open `chrome://extensions`.
2. Enable **Developer mode** in the top-right corner.
3. Drag and drop the downloaded `.crx` file onto the extensions page.
4. Accept the installation prompt.

Reference:

- [Chrome extension installation docs](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

## Firefox (.xpi)

1. Open `about:addons`.
2. Click the settings icon and choose **Install Add-on From File…**.
3. Select the downloaded `.xpi` file.
4. Confirm the installation prompt.

Reference:

- [Firefox extension installation docs](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/)
