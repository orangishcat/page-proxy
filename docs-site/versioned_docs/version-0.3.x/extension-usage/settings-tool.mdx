# Settings tool

New in v0.3.9: the sidepanel includes a dedicated Settings tool for options that
didn't fit within in the side panel UI.

## Grant toggles/local settings

- Temporarily suppresses declared grants for the selected saved script until you
  turn them back on.
    - Useful when you want to block scripts from running on page load (currently
      the only grant).
- For extension-wide suppression, use the global **Disable all grants** button
  in the code editor toolbar.

## Extension settings

- Shows or hides the Help button in the sidepanel toolbar.
