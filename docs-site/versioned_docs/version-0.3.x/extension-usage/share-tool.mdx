# Share tool

Share packages your current script from the editor.

Current behavior:

- `pp-script` export is available now.
    - New in v0.3.2: it exports the current editor contents as a `.js` file, using a snake-case version of the script title as the filename.
- Formats coming soon:
    - Tampermonkey script
    - CSS only
- Also planned is a minify option to minify the code.
- Exported filename is derived from script title metadata.

Use this tool to backup and share your scripts.
